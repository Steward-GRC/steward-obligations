# steward-obligations 🐹

> 🧭 Obligations, acknowledgements, completion reports and notifications for Steward

## 📦 Install

```bash
go get github.com/Steward-GRC/steward-obligations
```

```bash
task build    # go build ./...

task license  # check Apache-2.0 headers (golic)
```
